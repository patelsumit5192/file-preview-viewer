1. INTRODUCTION
--------------------------------------------------------------------------------
The file preview engine provides seamless, 100% client-side document viewing
directly inside the web browser. No external cloud servers, third-party iframe
viewers, or proprietary backend converters are used.

All rendering is performed locally using modular TypeScript plugins running on
the user's device. This ensures complete data privacy and sub-second rendering
performance for files of all sizes.

2. SUPPORTED DOCUMENT EXTENSIONS
--------------------------------------------------------------------------------
The preview system natively supports all standard office and document types:

  * PDF Documents:             .pdf
  * Microsoft Word:            .doc, .docx, .docm, .dot, .dotx, .dotm
  * Rich Text Format:          .rtf
  * OpenDocument Text:         .odt
  * Plain Text & Data:         .txt, .csv, .tsv, .log

3. CORE RENDERING ARCHITECTURE
--------------------------------------------------------------------------------
Each file format utilizes a dedicated, highly optimized preview plugin:

  - PDF Plugin:
    Utilizes Mozilla's PDF.js library with HTML5 Canvas output. Features
    dual-axis containment scaling, high-DPI retina display support, and
    interactive page navigation.

  - DOCX Plugin:
    Features high-fidelity OpenXML layout extraction with section break
    detection, embedded picture resolution, and graceful binary fallback.

  - DOC & Legacy Word Plugin:
    Direct binary parsing of the Compound File Binary Format (CFBF / OLE2).
    Extracts text streams from the WordDocument stream and Piece Tables,
    reconstructing headings, lists, and formatted paragraphs.

  - RTF Plugin:
    Parses Rich Text Format control words, font tables, and style definitions,
    rendering discrete pages with full page-by-page navigation.

  - OpenDocument Plugin:
    Extracts content.xml, styles.xml, and embedded media from ODF packages,
    respecting page dimensions and page-break markers.

4. USER CONTROLS & CAPABILITIES
--------------------------------------------------------------------------------
All documents benefit from a standardized toolbar with:
  [ < 1 / N > ]  Page navigation and jump
  [ Zoom +/- ]   High-precision zoom scaling
  [ Fit ]        Dual-axis auto-fit to visible viewport
  [ Rotate ]     90-degree clockwise orientation toggle
  [ Download ]   Instant client-side file save
  [ Print ]      Direct browser printing
