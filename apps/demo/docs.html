📦 Installation & Framework Setup

Install the universal library into your project using npm, pnpm, or yarn. One single dependency supports all frameworks and 50+ file formats.

npm
npm i @file-preview-viewer/viewer
pnpm
pnpm add @file-preview-viewer/viewer
yarn
yarn add @file-preview-viewer/viewer
React Component (JSX / TSX) 
import { FilePreview } from '@file-preview-viewer/viewer/react';
import '@file-preview-viewer/viewer/styles.css';

export function DocumentViewer({ fileUrl }) {
  return (
    <div style={{ width: '100%', height: '800px' }}>
      <FilePreview
        src={fileUrl} // URL string, File, Blob, or ArrayBuffer
        options={{
          theme: 'light',
          showToolbar: true,
          showFileName: true
        }}
        onLoaded={(meta) => console.log('Document loaded:', meta)}
      />
    </div>
  );
}

🎛️ PreviewViewerOptions Reference

Detailed guide for every configuration property passed into the viewer.

showToolbar boolean
Default: true
Controls whether the built-in toolbar (containing zoom, navigation, search, print, download, and fullscreen actions) is displayed or completely hidden.
💻 How to Set
<FilePreview
  src={file}
  options={{
    showToolbar: false // 👈 Hides toolbar completely
  }}
/>
<fp-file-preview
  [src]="fileSource"
  [options]="{
    showToolbar: false // 👈 Hides toolbar completely
  }"
/>
<FilePreview
  :src="file"
  :options="{
    showToolbar: false // 👈 Hides toolbar completely
  }"
/>
await viewer.preview(container, file, {
  showToolbar: false // 👈 Hides toolbar completely
});

// Or toggle dynamically anytime:
viewer.setShowToolbar(false); // Hide
viewer.setShowToolbar(true);  // Show
viewer.toggleToolbar();       // Toggle
👁️ What Effect It Has
  • When false: Completely removes the toolbar element from the DOM with zero vertical height, giving 100% of the viewport space to the document preview. Ideal for clean embed widgets or custom application toolbars.
  • When true: Renders the full toolbar equipped with zoom controls, search bar, download/print buttons, and page indicators.
  • Dynamic Switching: Can be toggled on-the-fly at runtime using viewer.setShowToolbar(boolean) or viewer.toggleToolbar() without reloading the file.
🎚️ Visual Difference: true renders the 40px action toolbar; false collapses it to 0px.

👁️ What Effect It Has
  • When true: Displays a sleek header bar above the toolbar with 📄 FileName.ext and a colored badge such as DOCX, PDF, or XLSX.
  • When false: Completely hides the title header bar, useful when your page already provides its own heading or tab title.
📄 Title Bar: 📄 Repository.xlsx [XLSX]

  • 'light': Crisp white background (#ffffff / #f8fafc), slate text, and light borders.
  • 'dark': Dark slate background (#0f172a / #1e293b), light text, dark toolbar and search inputs.
  • 'auto': Automatically responds to the user's OS system color preference via prefers-color-scheme media query.
🌓 Theme Mode: Toolbar and UI widgets seamlessly adapt without altering document page content.

Default: 'width'
Determines how pages and documents are automatically scaled to fit within the viewport on initial render and during window resize.

👁️ What Effect It Has
  • 'width' (Default): Automatically calculates zoom scale so document width comfortably spans the container width with minimal horizontal margins. Best for continuous vertical reading without horizontal scrolling.
  • 'page': Scales the document so that the entire height and width of a page fit within the viewport without requiring vertical scrolling for that page.
📐 Responsive Auto-Fit: ResizeObserver automatically recalculates fit scale on window or container resize.

🧩 Granular Toolbar Button Controls (ToolbarConfig)

You can keep the toolbar enabled while selectively disallowing or hiding specific buttons by passing booleans under toolbar: { ... } or directly on options.

Button / Action Option Key Default Effect When Set to false
Download (📥) download: false true Hides the download button, preventing users from downloading the raw file asset from the viewer toolbar.
Print (🖨️) print: false true Hides the print button to restrict printing from the viewer interface.
Open in Separate Window (↗️) openWindow: false true Hides the separate full window expansion button.
Search / Find (Ctrl+F) (🔍) search: false true Hides the in-document search button and disables the built-in search bar.
Thumbnails (⊞) thumbnails: false true Hides the thumbnail grid toggle icon.
Fullscreen (⛶) fullscreen: false true Hides the browser fullscreen toggle button.
Zoom In / Out (➕ / ➖) zoomIn: false, zoomOut: false true Hides the magnification increment and decrement buttons.
Fit to Width / Reset (↔ / 🔄) fitWidth: false, resetZoom: false true Hides the fit-to-width and zoom reset buttons.
Rotate CW / CCW (↻ / ↺) rotate: false (or rotateCW: false) true Hides page rotation buttons (PDF, Word, images).
Page Navigation (< [1] / N >) pageNav: false true Hides the page number input box and previous/next page chevron buttons.
Copy Text (📋) copy: false true Hides the text clipboard copy button (code, RTF, legacy documents).
Media Controls (▶, ⏸, ⏩, ⏪) play: false, speed: false, etc. true Hides playback controls for audio and video media files.

📡 Events & Lifecycle Callbacks

Listen to document lifecycle events, pagination changes, and zoom updates.

Event Payload Description
onLoading ('loading') { source } Fired immediately when file parsing and rendering starts.
onLoaded ('loaded') { metadata, plugin } Fired when the document is rendered, verified, and displayed to the user.
onError ('error') Error Fired if the document is corrupt or fails to render.
onPageChange ('page-change') { page, total } Fired automatically when scrolling down past pages or navigating pages.
onZoomChange ('zoom-change') { scale } Fired whenever the user zooms in, zooms out, or auto-fits.

⚡ Imperative API & Ref Methods

Control the viewer programmatically through component refs or the viewer instance.

React Ref Example (useRef) 
import { useRef } from 'react';
import { FilePreview, FilePreviewHandle } from '@file-preview-viewer/viewer/react';

export function ControlledViewer({ file }) {
  const viewerRef = useRef<FilePreviewHandle>(null);

  return (
    <div>
      <div style={{ marginBottom: 10, display: 'flex', gap: 8 }}>
        <button onClick={() => viewerRef.current?.setShowToolbar(false)}>Hide Toolbar</button>
        <button onClick={() => viewerRef.current?.setShowToolbar(true)}>Show Toolbar</button>
        <button onClick={() => viewerRef.current?.toggleToolbar()}>Toggle Toolbar</button>
        <button onClick={() => viewerRef.current?.fitToPage()}>Fit to Page</button>
        <button onClick={() => viewerRef.current?.resetZoom()}>Reset Zoom</button>
      </div>

      <FilePreview ref={viewerRef} src={file} />
    </div>
  );
}
Angular ViewChild Example 
import { Component, ViewChild } from '@angular/core';

export class MyComponent {

}
Vue 3 Template Ref Example 
<script setup>
import { ref } from 'vue';
import { FilePreview } from '@file-preview-viewer/viewer/vue';

const previewRef = ref(null);
const file = 'sample.pdf';

function hideToolbar() {
  previewRef.value?.setShowToolbar(false);
}

function toggleToolbar() {
  previewRef.value?.toggleToolbar();
}
</script>

<template>
  <button @click="hideToolbar">Hide Toolbar</button>
  <button @click="toggleToolbar">Toggle Toolbar</button>
  <FilePreview ref="previewRef" :src="file" />
</template>
Vanilla JavaScript Controller Example 
import { FilePreviewViewer } from '@file-preview-viewer/viewer';

const viewer = new FilePreviewViewer();
await viewer.preview(container, file);

// Programmatic controls:
viewer.setShowToolbar(false); // Hide toolbar
viewer.setShowToolbar(true);  // Show toolbar
viewer.toggleToolbar();       // Toggle toolbar
viewer.isToolbarVisible();    // returns boolean

viewer.setShowFileName(false);// Hide title header
viewer.setFileName('Custom Name.docx'); // Update name

viewer.fitToPage();           // Fit page
viewer.resetZoom();           // Reset zoom
viewer.zoomIn();              // Zoom in
viewer.zoomOut();             // Zoom out

await viewer.search('query'); // Find in document
viewer.findNext();            // Next match
viewer.findPrev();            // Previous match

viewer.toggleThumbnails();    // Toggle thumbnail drawer
viewer.toggleFullscreen();    // Toggle fullscreen
viewer.download();            // Trigger download
viewer.print();               // Trigger print
