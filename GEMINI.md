# Project Guidelines & Strict Rules

## ⚠️ STRICT FILE ACCESS RESTRICTIONS
- **NEVER use Google Drive files**: Under NO circumstances should any Google Drive files, directories, or cloud drives be accessed, read, used for testing, debugging, validation, or development, now or in any future session, unless the user explicitly grants permission.
- **Allowed Test Files**: Use ONLY local/sample files provided specifically for testing within the project workspace (e.g., `apps/demo/public/samples/`, `apps/demo/public/uploaded-samples/`, or project-local temporary files).
